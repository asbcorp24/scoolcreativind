# SHKIVR Student for Android

Нативное Android-приложение ученика для просмотра Classroom Remote.

## Первая версия

- сервер по умолчанию: `http://200.165.236.80:8080`;
- вход по ученическому PIN;
- имя ученика запоминается;
- WebSocket с автоматическим переподключением;
- WebRTC H.264 + Opus;
- просмотр трансляции преподавателя;
- звук лекции и приватный аудиотрек преподавателя;
- аннотации поверх трансляции;
- быстрые опросы;
- полноэкранный режим «Внимание»;
- кнопка «Поднять руку»;
- без камеры, микрофона, демонстрации экрана и удалённого управления.

## Сборка локально

Требуются JDK 17, Android SDK 36 и Gradle 8.13.

```bash
cd classroom-remote/android-student
gradle :app:assembleDebug
```

APK:

```
app/build/outputs/apk/debug/app-debug.apk
```
