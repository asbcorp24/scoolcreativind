# Школа креативных индустрий — Волжск

Технологичный сайт и CMS для **Школы креативных индустрий** на Laravel 9 + Bootstrap 5 + Three.js.

## Что уже реализовано

- футуристичная адаптивная главная;
- интерактивная Three.js-сцена на первом экране;
- динамические направления/студии;
- 6 стартовых студий из задания;
- отдельная страница каждой студии;
- фотогалерея;
- 360°-галерея на Three.js;
- интерактивные hotspot-точки внутри панорам;
- 3D-галерея GLB/GLTF;
- загрузка фото, 360° и 3D-файлов прямо из админки;
- видеогалерея с Rutube;
- проекты учеников / портфолио;
- новости;
- события и мастер-классы;
- форма записи на обучение;
- регистрация и вход;
- личный кабинет поступающего;
- просмотр собственных заявок и их статусов;
- админ-панель;
- создание новых разделов/студий;
- загрузка обложек;
- управление фото, 360° и Rutube;
- управление новостями;
- управление проектами учеников;
- управление событиями;
- обработка заявок на поступление.

## Требования

- PHP 8.0.2+ (рекомендуется PHP 8.1/8.2)
- Composer 2
- MySQL 5.7+/MariaDB 10.4+ или SQLite
- расширения PHP: mbstring, openssl, pdo, tokenizer, xml, ctype, json, fileinfo

Node.js для текущей версии не нужен: Bootstrap и Three.js подключены через CDN.

## Установка

```bash
git clone https://github.com/asbcorp24/scoolcreativind.git
cd scoolcreativind
composer install
cp .env.example .env
php artisan key:generate
```

Создайте БД, например:

```sql
CREATE DATABASE creative_school CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Укажите доступ в `.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=creative_school
DB_USERNAME=root
DB_PASSWORD=
```

Затем:

```bash
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Открыть:

```text
http://127.0.0.1:8000
```

## Медиа

### Фото

В разделе **Админ → Студии → Медиа** выберите тип «Фото» и укажите прямой URL изображения.

### 360°

Нужна эквидистантная панорама 2:1, например 6000×3000.  
Тип материала: **360° панорама**.

Для переходов внутри панорамы можно задать hotspots JSON, например:

```json
[{"label":"К звукозаписи","yaw":35,"pitch":-5,"target_url":"/studios/sound"}]
```

Просмотр работает через Three.js:
- мышь / палец — вращение;
- колесо — FOV / zoom.

Если панорама хранится на внешнем домене, сервер изображения должен разрешать CORS. Для продакшена лучше хранить панорамы на своём сервере.

### Rutube

Вставляется обычная ссылка:

```text
https://rutube.ru/video/VIDEO_ID/
```

На странице студии она автоматически превращается в embed-плеер.

## Структура контента

### Studios

Главные образовательные направления. Можно создавать сколько угодно новых разделов без изменения маршрутов и Blade-шаблонов.

### Media items

Типы:

- `photo`
- `panorama`
- `video`

### Student projects

Портфолио учеников. Флаг **«Показывать на главной»** выводит проект в общий showcase.

### Events

Дни открытых дверей, мастер-классы, премьеры, выставки и другие события.

### News

Новостная лента с отдельной страницей каждой публикации.

### Admission applications

Заявки на поступление со статусами:

- новая;
- в обработке;
- принята;
- отклонена.

## 3D модели

В разделе **Админ → Студии → Медиа** выберите тип **3D модель GLB/GLTF**.

Можно:

## Локальные JS/CSS без CDN

Bootstrap, Three.js и 3D `model-viewer` больше не загружаются с внешних CDN. Они устанавливаются через npm и собираются Vite в локальный каталог:

```text
/public/build/
```

После `git pull` обязательно выполнить:

```bash
npm install
npm run build
php artisan optimize:clear
```

В production браузер должен загружать фронтенд только с вашего домена, например:

```text
https://ваш-домен/build/assets/app-....js
https://ваш-домен/build/assets/app-....css
https://ваш-домен/css/site.css
```

Ссылок на `cdn.jsdelivr.net` и `unpkg.com` в layout больше нет.

Если на production-сервере Node.js не установлен, выполните `npm install && npm run build` на компьютере разработки и перенесите целиком каталог `public/build` на сервер вместе с новой версией проекта.
